# Happy Clarinet reference guide

[Happy Clarinet](https://happyclarinet.com/) provides a free browser-based fingering reference for standard Boehm B-flat soprano clarinet, with note diagrams, synthesized reference tones and printable charts. This guide is maintained by the site creator and does not publish the private application source.

## Read the legend first

A fingering diagram only makes sense with its legend. Check which marks mean a closed hole, an open hole or a pressed key. Identify left-hand and right-hand positions before using the diagram on your instrument. Different clarinet systems can require different references.

## Written pitch versus sounding pitch

B-flat clarinet is a transposing instrument. A written C sounds as concert B-flat, a major second lower. When checking a reference tone or tuner, first establish whether it labels written pitch or concert pitch. Comparing the same letter name in two different conventions can make a correct fingering appear wrong.

| Written pitch | Concert pitch |
| --- | --- |
| C | B-flat |
| D | C |
| E | D |

## A deliberate practice routine

1. Find one written note in the [clarinet reference](https://happyclarinet.com/).
2. Read the entire diagram, including any register-key indication.
3. Set your fingers slowly before playing. Do not use a fingering chart as a diagnosis of embouchure or air support.
4. Compare with a teacher-approved reference or the appropriate pitch convention on your tuner.
5. Record the written note, the fingering you used and the next question to ask your teacher.

## Limits of a browser reference

Synthesized tones are pitch references, not recordings of a clarinet. Fingering choices can depend on instrument design, register and musical context. A chart supplements instruction rather than replacing it.
